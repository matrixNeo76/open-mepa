METODOLOGIA ZERO-COMPLICAZIONI

Come Gestire Bandi & Gare in modo Semplice, Diretto e Immediato

Il ciclo di vita completo di una gara pubblica in 4 passaggi sequenziali, memorizzato e velocizzato dal motore relazionale SQLite locale.

Tempo medio/gara: ~5-10 min
FASE 1: Identificazione Rapida

Caricamento e Presa in Carico

Importa il file JSON/CSV da Consip o premi "Nuova Gara". Il sistema associa automaticamente il CIG, la stazione appaltante, la regione e la categoria merceologica, memorizzandola nel database SQLite.

FASE 2: Valutazione (Go / No-Go)

Filtrare senza Perdere Tempo

Usa la scorciatoia "Mie Categorie" per isolare Informatica e Cancelleria. Se mancano requisiti o i margini sono bassi, imposta lo stato su Scartata. Se idonea, imposta In Lavorazione.

FASE 3: Predisposizione Buste & Invio

Le 3 Buste Telematiche

Separa rigorosamente Busta A (Amministrativa), Busta B (Tecnica) e Busta C (Economica). Firma digitalmente in formato CAdES (.p7m) e trasmetti almeno 24 ore prima per evitare blocchi SPID.

FASE 4: Esito, Aggiudicazione & Storico

Chiusura e Svincolo Garanzie

Segna la gara come Vinta o Persa. Richiedi subito la lettera di svincolo della cauzione provvisoria per liberare il castelletto bancario ed esporta il database SQLite 3 o CSV a fine mese per lo storico.

CREATE TABLE IF NOT EXISTS gare (
  id TEXT PRIMARY KEY,
  cig TEXT UNIQUE,
  category TEXT,
  region TEXT,
  source TEXT,
  authority TEXT,
  title TEXT,
  amount REAL,
  deadline TEXT,
  status TEXT,
  owner TEXT,
  link TEXT
);
CREATE INDEX IF NOT EXISTS idx_cig ON gare(cig);
CREATE INDEX IF NOT EXISTS idx_category ON gare(category);
CREATE INDEX IF NOT EXISTS idx_deadline ON gare(deadline);
